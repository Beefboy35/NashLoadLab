# Как использовать навык в Codex

Распакуйте архив в корень репозитория. Файл навыка окажется по пути `.agents/skills/nash-load-lab/SKILL.md`.

Затем обратитесь к Codex с запросом:

`$nash-load-lab Полностью реализуй исследовательское приложение в этом репозитории согласно SKILL.md и всем references. Пройди весь путь от математического ядра Go, SQLite и API до React-интерфейса, графиков, воспроизводимых опытов и тестов. Покажи реальные результаты запуска и проверки, не останавливайся на макетах.`

Навык не является готовой программой: он задаёт Codex точные требования и критерии проверки. Если Codex не видит навык, проверьте путь и перезапустите сессию.
